<p align="justify"> <strong>Программа для работы кассира</strong> — учебное кассовое приложение, разработанное на Python с использованием Tkinter. Проект предназначен для автоматизации основных операций кассира: открытия и закрытия смены, поиска товаров по штрихкоду, формирования продаж, учёта денежных средств в кассовом ящике и сохранения истории операций. </p>

<p align="justify"> Информация о товарах хранится в редактируемом файле <code>codes.ods</code>. Для каждого товара указываются штрихкод, название и цена. Кассир может отсканировать или ввести штрихкод, после чего программа находит соответствующий товар и добавляет его в текущую продажу. </p>

<p align="justify"> Информация о завершённых продажах и кассовых сменах сохраняется в базе данных <code>orders.db</code>. Каждая продажа связывается с кассиром и открытой сменой, а завершённым заказам автоматически присваиваются номера вида <code>ORD-000001</code>. </p>

<h3>Работа с кассовыми сменами</h3>

<p align="justify"> Перед началом работы пользователь выбирает кассира и открывает кассовую смену. При открытии указывается начальный остаток денежных средств в кассовом ящике. </p>

<p align="justify"> Во время смены программа учитывает продажи и позволяет регистрировать ручное внесение или изъятие наличных. При закрытии кассы вводится фактически пересчитанная сумма. Программа рассчитывает ожидаемый остаток и сохраняет возможное расхождение. </p>

<p align="justify"> Если приложение было закрыто до завершения смены, незакрытая смена автоматически восстанавливается при следующем запуске. </p>

<h3>Хранение и контроль данных</h3>

<p align="justify"> Для проверки целостности финансовой базы используется контрольная сумма SHA-256. При запуске программы содержимое <code>orders.db</code> сравнивается с сохранённой контрольной суммой из <code>orders.db.sha256</code>. После штатного изменения данных контрольная сумма обновляется автоматически. </p>

<p align="justify"> Основные действия программы записываются в файл <code>cash_register.log</code>: запуск и завершение работы приложения, открытие и закрытие смен, сканирование товаров, проведение продаж, внесение и изъятие наличных, проверка целостности базы и возникающие ошибки. Журнал можно открыть непосредственно из интерфейса программы в режиме только для чтения. </p>

<h3>Основные возможности</h3>

<ul> <li>выбор кассира перед началом работы;</li> <li>открытие и закрытие кассовой смены;</li> <li>поиск товаров по штрихкоду;</li> <li>формирование и сохранение продаж;</li> <li>автоматическая нумерация заказов;</li> <li>учёт наличных в кассовом ящике;</li> <li>внесение и изъятие денежных средств;</li> <li>расчёт ожидаемого и фактического остатка кассы;</li> <li>восстановление незакрытой смены после перезапуска;</li> <li>ведение журнала действий;</li> <li>проверка целостности базы данных с помощью SHA-256;</li> <li>сборка автономного Windows-приложения.</li> </ul>

<h3>Технологии</h3>

<p align="justify"> Проект написан на <strong>Python</strong>. Графический интерфейс создан с помощью <strong>Tkinter</strong>. Для хранения данных о товарах используется таблица <strong>ODS</strong>, а операции и сведения о кассовых сменах сохраняются в локальной базе данных. </p>

<p align="justify"> Для Windows предусмотрена сборка программы в отдельный <code>CashRegister.exe</code> с помощью PyInstaller. Приложение можно запускать без консольного окна, а рабочие файлы создаются и хранятся рядом с исполняемым файлом. </p>

<h3>Цель проекта</h3>

<p align="justify"> Основная цель проекта — разработать самостоятельное настольное приложение, моделирующее работу кассового рабочего места, и на практике реализовать работу с графическим интерфейсом, локальным хранением данных, кассовыми сменами, журналированием операций и контролем целостности данных. </p>
